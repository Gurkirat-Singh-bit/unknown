# Local fonts

These normal-style variable fonts are bundled with the shared UI stylesheet:

- `DM-Sans-variable.ttf`: DM Sans, weights 100–1000, including optical sizing.
- `Manrope-variable.ttf`: Manrope, weights 200–800.

The browser loads the files from this app's generated static assets. There are no
runtime requests to Google Fonts. Each font's SIL Open Font License is included
in this directory.

Original files:

- DM Sans: https://github.com/google/fonts/blob/main/ofl/dmsans/DMSans%5Bopsz%2Cwght%5D.ttf
- Manrope: https://github.com/google/fonts/blob/main/ofl/manrope/Manrope%5Bwght%5D.ttf
